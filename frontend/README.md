# 다시봄 스쿨 프론트엔드

AI 카메라를 이용한 어린이 분리배출 교육 게임의 P0 프론트엔드입니다.

## 구현된 핵심 흐름

1. 학급 코드 참여 (`4B7K2M`)
2. 익명 닉네임 설정
3. 학생 홈과 오늘의 미션
4. 브라우저 카메라 촬영 또는 데모 사진
5. Mock AI 2단 분석
6. 분리배출 행동 안내
7. After 재촬영
8. 카드와 경험치 보상
9. 헷갈림 도감

## P1 확장 기능

- 오늘의 미션 상세와 진행률
- 캐릭터 3단계 성장 화면
- 행동 뱃지와 달성 진행률
- 학급 공동 목표
- 우리 학교 5문항 체크리스트와 결과
- 음성 안내·큰 글씨 설정
- 교사 체험 로그인
- 학급 누적 카드·교정률·미션 현황판
- 익명 학생 참여 현황
- 참여 코드 복사·재발급
- 학급 잠금·해제
- 공동 목표 인증서 미리보기

## P2 안정화·운영 기능

- 오프라인 상태 자동 감지와 안내
- 서비스 워커 기반 앱 셸 캐시
- 인터넷 장애 시 저장된 AI 판정 폴백
- 촬영 세션 30분 임시 복구
- AI 응답 지연·타임아웃 복구 화면
- 정상·캐시·지연 테스트 전환
- 충북 특화 도감 카드와 필터
- 교사용 콘텐츠 게시·초안 전환
- 다른 학급 비교 기능 선택 설정
- 인쇄용 학급 공동 목표 인증서
- P2 필수 파일 자동 검증 테스트

## 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run lint
npm run build
npm test
```

실제 API 연동 시 `app/mockData.ts` 대신 백엔드 판정 세션 API의 응답을 사용합니다.

교사용 체험 계정은 로그인 화면에 자동 입력됩니다.
